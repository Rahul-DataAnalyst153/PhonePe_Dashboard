## 📌 Project Overview

The **PhonePe Transaction & Payment Performance Dashboard** is an interactive Power BI project developed to analyse digital payment transactions, service performance, customer behaviour, transaction trends, and payment success and failure patterns.

This dashboard transforms transaction data into meaningful business insights through interactive visualisations, KPI cards, charts, tables, and filters.

It helps understand transaction performance, payment trends, customer demographics, service usage, and reasons behind failed transactions.

## 📊 Dashboard Pages

### 🏠 1. Home

The Home page serves as the landing page of the dashboard.

**Features:**
- Introduction to the PhonePe platform.
- Navigation to all dashboard sections.
- PhonePe-inspired purple theme.
- Clean and user-friendly dashboard layout.

### 📈 2. Overview

The Overview page provides a high-level summary of transaction performance and business activity.

**Key Performance Indicators (KPIs):**
- Total Transactions: 25K
- Total Transaction Value: 282.91M
- Average Transaction Value (ATV): 11.54K
- Unique Users: 21.91K
- Successful Transaction Rate: 95.94%

**Business Analysis:**
- Month-over-Month Transaction Growth.
- Month-over-Month Transaction Value Growth.
- Weekday vs Weekend Usage.
- Monthly and Quarterly Transaction Trends.
- Age Segment Contribution.
- Top 5 Users by Transaction Value.
- Service Transactions by Service Value.

### 💳 3. Service & Transaction Analysis

This page focuses on analysing service-wise transaction performance and usage patterns.

**Key Analysis:**
- Top 7 Services by Transaction Amount.
- Monthly Service Transaction Value.
- Most Frequently Used Services.
- Service-wise Transaction Distribution.
- Service Performance Comparison.

**Services Analysed:**
- Mutual Fund
- Gold Loan
- Bike Loan
- Credit Score
- Health
- Term Life
- Car
- Insurance
- Loans
- Money Transfer
- Recharge Bills
- UPI ID
- QR Code
- Mobile Number

### 👥 4. Customer & User Analysis

This page provides insights into customer demographics, age groups, and transaction behaviour.

**Key Analysis:**
- Age Group-wise Transaction Amount.
- Age Group-wise Transaction Count.
- Year-wise Transaction Amount.
- Age Segment Contribution.
- Age Group-wise User Count.
- Service Transaction Amount by Age Group.

**Customer Segments:**
- Gen Z
- Millennials
- Gen X
- Baby Boomers

### 📅 5. Transaction Trends & Behaviour

This page analyses transaction patterns across different time periods.

**Key Analysis:**
- Monthly Transaction Trends (Top & Bottom).
- Weekly Transaction Trends (Top & Bottom).
- Monthly Transaction Growth Percentage.
- Monthly Transaction Amount Growth Percentage.
- Service-wise Monthly Transaction Analysis.
- Insurance Performance.
- Loans Performance.
- Money Transfer Performance.
- Recharge Bills Performance.

**Interactive Features:**
- Month-wise Filters.
- Payment Status Filters.
- Service Category Selection.

### ⚠️ 6. Payment Performance & Failure Analysis

This page focuses on payment success rates, failed transactions, and reasons behind payment failures.

**Key Analysis:**
- Payment Status Distribution.
- Failed vs Successful Transactions.
- Failure Transactions by Reason.
- Payment Status by Service.
- Service-wise Failure Analysis.
- Service-wise Successful Transactions.
- Transaction Amount and Failure Breakdown.

**Failure Reasons Analysed:**
- Server Error
- Insufficient Amount
- Wrong PIN

## 🚀 How to Use

1. Open the Google Drive link provided in the Project Files & Dataset section.
2. Download the Power BI (`.pbix`) file and supporting dataset.
3. Open the `.pbix` file using Microsoft Power BI Desktop.
4. Connect the dataset if prompted.
5. Update the data source path if necessary.
6. Refresh the data.
7. Explore all six dashboard pages using interactive filters and navigation.
